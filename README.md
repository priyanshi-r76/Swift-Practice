# Swift Practice 🧑‍💻

A collection of Swift coding exercises, practice questions, and Swift Playgrounds created while learning the Swift programming language.

This repository serves as my personal learning space to strengthen my programming fundamentals, practice problem-solving, and build a solid foundation for iOS development.

## 📚 Topics Covered

- **Swift Basics** — Variables, constants, data types, and operators
- **Control Flow** — Conditions, loops, and switch statements
- **Functions** — Parameters, return values, and closures
- **Collections** — Arrays, dictionaries, and sets
- **Optionals** — Optional binding, unwrapping, and nil coalescing
- **Enumerations** — Enums, associated values, and raw values
- **Structures & Classes** — Properties, methods, and initializers
- **Protocols & Extensions** — Protocol-oriented programming
- **Error Handling** — `throws`, `try`, and `catch`
- **Advanced Swift** — Generics, higher-order functions, and memory management
- **Problem Solving** — Logic-building exercises and coding challenges

*The structure is illustrative and can evolve as more exercises are added.*

## 🧪 Swift Playgrounds

Swift Playground files are used to experiment with Swift syntax, test code snippets, understand language concepts, and practice small programming problems.

Each playground may contain:
- Concept explanations and examples
- Coding exercises and solutions
- Experiments with different Swift features
- Notes and observations from practice

## 🎯 Goals

- Develop a strong understanding of Swift fundamentals.
- Improve logical thinking and problem-solving skills.
- Practice writing clean, readable, and reusable code.
- Understand Swift language features through hands-on experimentation.
- Prepare for building native iOS applications using SwiftUI.
- Track my progress as I learn Swift step by step.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the repository:

   ```bash
   cd Swift-Practice
   ```

3. Open a `.playground` file in Xcode.

4. Run the code and experiment with the examples and exercises.
